# Certificate Verification Portal

Welcome to the official **Certificate Verification Portal** of **GEOCODING LAB**. This portal allows graduates, academic institutions, employers, and organizations to independently verify the validity and authenticity of certificates issued for the **Geospatial Programming Course**.

---

## 🔍 How to Verify a Certificate

1. Locate the **Certificate ID** (format: `GPC-C<Cohort>-<Number>`, e.g., `GPC-C2-001`) printed on the official certificate.
2. Search or browse for the Certificate ID in the **Official Graduate Registry** below.
3. Confirm that the **Participant Name**, **Cohort / Track**, and **Completion Date** match the physical or digital certificate presented.
4. If a Certificate ID is missing or details do not match, please contact us at [geocoder.contact@gmail.com](mailto:geocoder.contact@gmail.com) for manual verification.

## ➕ Adding New Graduate Records (For Instructors)

To register a new certificate recipient, add a new entry to the registry table above using the following format:

```markdown
| `GPC-C2-XXX` | Participant Full Name | Geospatial Programming (Cohort-X) | Month Year | :white_check_mark: Verified | [Link/Status](#) |
```

Alternatively, individual digital certificate PDF or image scans can be placed in this folder (`docs/certificates/`) and linked directly.
