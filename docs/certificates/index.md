# Certificate Verification Portal

Welcome to the official **Certificate Verification Portal** of **GEOCODING LAB**. This portal allows graduates, academic institutions, employers, and organizations to independently verify the validity and authenticity of certificates issued for the **Geospatial Programming Course**.

---

## 🔍 How to Verify a Certificate

1. Locate the **Certificate ID** (format: `GPC-C<Cohort>-<Number>`, e.g., `GPC-C2-001`) printed on the official certificate.
2. Search or browse for the Certificate ID in the **Official Graduate Registry** below.
3. Click **View Record** to open the student's dedicated verification page with their certificate details and PDF.
4. Confirm that the **Participant Name**, **Cohort / Track**, and **Completion Date** match the physical or digital certificate presented.
5. If a Certificate ID is missing or details do not match, please contact us at [geocoder.contact@gmail.com](mailto:geocoder.contact@gmail.com) for manual verification.

## ➕ Adding New Graduate Records (For Instructors)

To register a new certificate recipient, add a new entry to the registry table above using the following format:

```markdown
| `GPC-C2-XXX` | Participant Full Name | Geospatial Programming (Cohort-X) | Month Year | :white_check_mark: Verified | [View Record](./cohort-2/gpc-c2-xxx.md) |
```

Also create a corresponding `gpc-c2-xxx.md` file in `docs/certificates/cohort-2/` using the existing files as a template, and place the PDF in the same folder.
